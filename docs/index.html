Features

Everything a structural logging campaign needs, in one window.

What 1.9.6 does today, and what 2.0 adds: the items marked New arrive with the 2.0 release.

Drillcore logging

Log planes, lines and lines on planes with alpha, beta and gamma, or type true orientations and rake directly. True dip, dip direction, trend and plunge are computed as you type from the hole survey, by minimum curvature, balanced tangential or tangential desurveying.

Stereonet and statistics

Lower-hemisphere equal-area net with Kamb and Gaussian density contouring, great circles, Terzaghi correction, colour by any column, freeform polygon sets, and full directional statistics: Fisher, Bingham, Woodcock and eigenvector analysis, saved as analyses and compiled per hole.

Sections New in 2.0

Vertical, plan and inclined sections with a corridor either side of the plane, best-fit sections through selected holes, structures as ticks and arrows, and drawings that can be traced, styled and exported to DXF.

Meshes and distances New in 2.0

Import Leapfrog surfaces and solids as DXF, OBJ or STL, see them in 3D and cut on every section, trace a cut as a drawing, and compute the signed distance of each structure to a surface to assign hanging wall and footwall sets.

3D view

Desurveyed hole traces, plane discs with poles, lineation arrows, interval tubes, point markers and meshes in an OpenGL scene with a clipping slab, camera presets, and bars for numeric columns.

Downhole logs

Strip logs of several holes side by side against a shared depth axis, with interval, point and orientation tracks, value bars for assays and other numeric columns, and the same colours and filters as every other view.

Datasets and user columns

Add interval tables for lithology, alteration, RQD or assays and point tables beside the structures. User columns become filters, colour sources and set columns, and a sortable table of tens of thousands of rows stays responsive.

Import and export

An import wizard for CSV and Excel with column mapping and type checks, export of every table with 3D coordinates, figures as PNG or SVG, sections and drawings as DXF, and batch figures for every hole in one step.

Filters and sets

Filter by hole, set, key observation or any column expression, and every view follows. Orientation sets live in the table as ordinary columns, so they export, filter and colour like any other value.

Workflow

Import the survey, log the core, read the answer.

Set up the project

Create a logging project, then bring in collars and surveys from CSV or Excel through the import wizard. Existing structure files with alpha and beta, or with manually measured orientations, come in the same way.

Log and check

Type alpha, beta and gamma at the depth of each measurement. The true orientation appears at once, the pole lands on the net, and the structure is drawn in section, in 3D and on the log, so an implausible reading is caught at the core tray.

Interpret and deliver

Draw sets on the net, compare them across holes and against modelled surfaces, and export the tables, the figures and the sections in the formats the rest of the project uses.

In use

The views work together.

Selecting a measurement in one view highlights it in every other, and the filters, sets and colours are shared.

Free, without limit

The standalone stereonet costs nothing.

A stereonet project takes field measurements or any orientation dataset without drillholes and gives the whole net toolset: contouring, sets, statistics, filters, colour by column and figure export. It never expires and needs no licence, so it can be used for teaching, field mapping and quick checks of any orientation data.
